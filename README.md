# LAST FREQUENCY — музыкальный плеер

Отдельная версия плеера с сохранёнными функциями: воспроизведение, плейлисты, мини-плеер, темы, Discord и загрузчик. Список треков и анимации оптимизированы для меньшей постоянной нагрузки. Настройки и кэш этой версии изолированы от прежней.

## Установка

1. Распакуй архив куда угодно, например в `D:\LastFrequency\`.
2. Один раз запусти `install_dependencies.bat`: он устанавливает зависимости тем же интерпретатором Python, который использует `start_player.vbs`, и проверяет Discord Rich Presence и онлайн-поиск. Это предотвращает классическое «поставил пакеты, но не туда».
3. Запускай двойным кликом по `start_player.vbs`. Плеер откроется в собственном окне без системной рамки: сверху прямая панель с кнопками окна, крестик прячет окно в трей (поведение можно изменить в **Настройки → Прочее**). Если встроенное окно по какой-то причине не стартует, плеер откроется в окне Edge/Chrome без вкладок.

Нужен Python 3.9 или новее. Лаунчеры ищут его в `%LOCALAPPDATA%\Python\pythoncore-3.14-64\`, а если там нет — используют команду `py`.

## Состав папки

```
LastFrequency\
├── player.py                  сервер, окно и логика плеера
├── mini_player.py             плавающий мини-плеер
├── web\index.html             интерфейс
├── start_player.vbs           запуск без чёрного окна
├── start_player_debug.bat     запуск с окном, показывает ошибки и самопроверку
├── install_dependencies.bat   установка зависимостей для того же Python
├── build_exe.bat              запуск сборки .exe (вызывает build_exe.ps1)
├── build_exe.ps1              зависимости, FFmpeg и сборка по .spec
├── LastFrequency.spec              описание сборки PyInstaller (один .exe)
├── prepare_ffmpeg.ps1         загрузка ffmpeg.exe и ffprobe.exe для сборки
├── build_installer.bat        запуск сборки установщика (вызывает build_installer.ps1)
├── build_installer.ps1        поиск Inno Setup и сборка установщика
├── LastFrequency.iss          сценарий Inno Setup
├── icon.ico                   иконка для .exe
├── requirements.txt
├── music\                     создаётся сама: сюда можно кидать свои треки
├── backgrounds\               создаётся сама: загруженные картинки для фона
├── logs\player.log            создаётся сама: логи
└── player_settings.json       создаётся сама: все настройки
```

Плеер ничего не пишет за пределами своей папки. Чтобы перенести его на другой ПК или в другое место, просто скопируй папку целиком.

## Сборка в .exe и установщик

1. Запусти `build_exe.bat` в Windows (нужны интернет и Python). Зависимости и FFmpeg с ffprobe устанавливаются автоматически, сама сборка описана в `LastFrequency.spec`.
2. После сборки появится **`dist\LastFrequency.exe`** — один файл, в котором уже лежат интерфейс и FFmpeg. Python для запуска больше не нужен.
3. Чтобы сделать установщик, поставь [Inno Setup 6](https://jrsoftware.org/isinfo.php) и запусти `build_installer.bat`: получится **`dist\LastFrequency-Setup.exe`** (он берёт готовый `dist\LastFrequency.exe`, поэтому сначала собирай .exe).

В .exe не попадают пользовательские файлы: настройки, музыка, фоны, кэш и логи создаются в папке рядом с `.exe`, чтобы деинсталлятор мог удалить их вместе с плеером. При первом запуске профиль предыдущей версии переносится рядом с установленным `.exe` и удаляется из AppData после успешного переноса. Эта сборка использует порт `8775`, поэтому может работать рядом с исходной версией.

Первый запуск .exe может занять несколько секунд (он распаковывается во временную папку), а Windows SmartScreen или антивирус иногда ругаются на неподписанные .exe из PyInstaller: нажми «Подробнее → Выполнить в любом случае».

## Режимы работы

`Настройки → Прочее → Режим работы`. Смена режима применяется после перезапуска: плеер сам запускает новую копию, дожидается закрытия старой (если она зависла, завершает её принудительно) и открывает окно заново.

- **ЭкоОнлайн** — глобальный поиск в YouTube, SoundCloud, Deezer и Apple Music; Spotify и Яндекс Музыка открываются быстрыми поисковыми ссылками. Доступна загрузка MP3, тяжёлые визуальные эффекты и мульти-треки отключены.
- **Онлайн** — полный режим с глобальным поиском, загрузкой MP3, визуализатором и остальными эффектами.
- **ЭкоОффлайн** — локальная музыкальная библиотека, Discord и мини-плеер; онлайн-поиск и загрузка отключены, нагрузка уменьшена.
- **Оффлайн** — локальная библиотека без онлайн-поиска и загрузки, но с визуальными эффектами.

Выбор режима применяется после перезапуска. Параметр влияет на доступность поиска и загрузчика, а не только на внешний вид интерфейса.

## Мульти-треки

Режим, где несколько треков играют одновременно. Включается в **Настройки → «Мульти-треки»** или кнопкой **«Мульти»** над списком.

- Клик по треку **накладывает** его поверх уже играющих (до 8 одновременно). Повторный клик по нему убирает его.
- У каждого трека в панели сверху: пауза/play, **кнопка цикла**, своя громкость, отдельная перемотка и крестик. Нижний ползунок громкости — общий для всех.
- В настройках можно сделать так, чтобы новые треки сразу ставились в цикл.
- Набор треков, циклы и громкость запоминаются: при следующем запуске «сцена» вернётся на паузе.
- Кнопка «Играть» над списком выключает мульти-режим и запускает обычное воспроизведение. В Discord показывается «Трек 1 + Трек 2 + …».

## Откуда плеер берёт треки

Настройки → «Треки». Плеер читает все папки из списка вместе с подпапками, каждая подпапка становится плейлистом.

- **Папка music** рядом с `player.py` — для своих файлов (mp3, m4a, flac, ogg, opus, wav, aac).
- **Папка бота** — `downloads\SoundCloud` внутри ReClip-Bot. Плеер находит её сам, если папка бота (в которой лежит `bot.py`) стоит рядом с папкой плеера или плеер лежит внутри неё. Иначе нажми «Папка…» у этой строки и выбери папку бота.
- **Свои папки** — кнопки «Обзор…» или «Добавить». Любую папку можно отключить галочкой.

## Оформление

Настройки → «Оформление» и «Фон»: темы, включая «ZXC Dead Inside», профиль «Своя тема» с настройкой нескольких цветов фона, панелей и текста, акцент, шрифт, скругление, прозрачность панелей, плотность списка и визуализатор. Пульсацию панелей под битом можно отключить; визуализатор сердца стал заметнее, огненный вариант визуализатора убран. В качестве фона можно выбрать тему, однотонный цвет, картинку, обложку текущего трека или собственный градиент. Для своего градиента доступны два цвета и линейный, радиальный или конусный стиль.

## Поиск и пользовательские плейлисты

- На главной можно выбрать источник поиска: все поддерживаемые площадки, YouTube, SoundCloud, Deezer или Apple Music. Spotify и Яндекс Музыка остаются быстрыми переходами на их собственные страницы поиска.
- Онлайн-треки можно добавлять в пользовательский плейлист без скачивания. Плейлисты хранят метаданные и ссылку на источник в локальном хранилище браузера, чтобы записи оставались после перезапуска приложения. Для YouTube/SoundCloud аудиопоток разрешается заново при воспроизведении.

## Поиск и скачивание MP3

Открой **Настройки → Загрузки MP3**. По названию ищутся отдельные треки на YouTube и SoundCloud; выбери результат и папку назначения. Одиночный трек можно сохранить в плейлист библиотеки или выбрать папку на компьютере; выбранная папка автоматически добавляется в источники музыки. По ссылке плеер различает видео/трек и плейлист: одиночный трек спросит место сохранения, а плейлист сохранит в папку с его названием. Загрузка показывает прогресс и поддерживает отмену. Папку загрузки можно задать в этой же вкладке. Все загрузки преобразуются в MP3. Новые файлы отслеживаются автоматически. DRM-защищённые треки пропускаются с одним сообщением об ошибке: плеер не обходит DRM. Загрузки быстрее используют параллельные фрагменты YouTube, когда источник это поддерживает. Плейлисты можно перетаскивать в боковом списке; источник YouTube или SoundCloud отмечается отдельной иконкой. Загрузчик выключается сам через 60 секунд после последней загрузки. Для сборки `.exe` используются `yt-dlp`, `imageio-ffmpeg`, `watchdog`, а скрипт сборки включает `ffmpeg.exe` и `ffprobe.exe`.

## DVD заставка

В **Настройки → Прочее** можно добавить несколько летающих картинок, настроить их размер и вращение. Они двигаются по разным частям окна и находятся под панелью песен. Движение обновляется 30 раз в секунду, вращение — 15: так окно перерисовывается реже и тратит меньше энергии.

## Визуализатор

**Настройки → Визуальные эффекты.** Эффект (столбики, волна, сердце), цвет, свечение и прозрачность, а также:

- **Где показывать** — «На фоне окна» (на весь экран за панелями) или «В нижней панели» (маленькое поле между кнопками управления и громкостью). Второй вариант заметно экономнее: перерисовывается не всё окно, а небольшой холст. В узком окне (меньше ~1080 px) поле в панели скрывается.
- **Частота кадров** — 10, 15, 20, 30, 45 или 60 кадров/с. Чем меньше, тем ниже нагрузка.

## Мини-плеер

Появляется, когда главное окно спрятано в трей. Прозрачность и размер меняются кнопками прямо на мини-плеере и запоминаются; в основных настройках этих пунктов больше нет.

## Усилитель громкости

**Настройки → Прочее → Звук.** Усиливает треки до 25× отдельно от основного ползунка громкости. Включён ограничитель пиков и мягкое ограничение, чтобы на больших значениях не было жёсткого цифрового клиппинга, но громко и искажённо всё равно будет — повышай постепенно.

## Discord

Настройки → «Discord». Включи показ трека и открой Discord на этом компьютере. Если статус не отображается, проверь в Discord, что показ активности разрешён. Application ID уже задан в настройках плеера.

## Управление

Пробел — пауза, `←` `→` — перемотка (с Shift — по 15 с), `↑` `↓` — громкость, `N` / `P` — следующий / предыдущий, `S` — перемешать, `R` — повтор, `M` — без звука, `F` — в избранное, `/` — поиск, `Esc` — закрыть окно. Медиа-клавиши клавиатуры тоже работают.

## Если что-то не работает

Запусти `start_player_debug.bat`: он закроет старую копию плеера, напечатает самопроверку (где лежат файлы, что установлено) и покажет ошибки. То же самое руками: `python player.py --check`.

## Безопасность

Плеер слушает только `127.0.0.1` и закрыт случайным токеном, который создаётся при каждом запуске. Из интернета и из других сайтов в браузере он недоступен. Файлы отдаются только из папок, которые указаны в настройках.


### Пользовательские плейлисты — экспорт и импорт

В блоке «Плейлисты» кнопка «ZIP» скачивает открытый пользовательский плейлист архивом `.zip`: внутри лежат аудиофайлы в `Tracks/`, `playlist.json` и `README.txt`. Кнопки «Импорт» и «ZIP» находятся над списком треков рядом с «Мульти» и «Выбрать». При экспорте откроется диалог «Сохранить как» и можно выбрать папку и имя файла; если диалог недоступен, файл попадёт в папку «Загрузки» браузера. Кнопка «Импорт» загружает JSON-манифест после распаковки ZIP; сами аудиофайлы нужно положить в папку музыки и выполнить сканирование библиотеки. При импорте треки сопоставляются по ID, затем по названию и исполнителю.


ПКМ отключён внутри интерфейса плеера. Также блокируются стандартные сочетания открытия DevTools/исходника, но это не является защитой от технически подкованного пользователя.

### Обложка трека в Discord

Если включён Discord Rich Presence, в статусе показывается обложка играющего трека (из тегов mp3 или картинка в папке трека). Discord не может взять файл с твоего ПК, поэтому плеер уменьшает обложку до 512 px, временно выкладывает её на бесплатный файлообменник, а Discord получает оттуда ссылку.

Хосты пробуются по очереди: Litterbox, uguu.se, 0x0.st, tmpfiles.org и, в последнюю очередь, catbox.moe. Если хост отвечает ошибкой, не успевает или отдаёт не картинку, плеер переходит к следующему, а упавший хост на пару минут пропускается. Если все хосты недоступны, загрузка повторяется сама (через 20 с, 40 с, 80 с и 160 с), пока играет этот трек. Одинаковые обложки грузятся один раз, ссылки кэшируются в `discord_covers.json` с учётом срока жизни файла на хосте. Что именно происходит, видно в `logs\player.log`. Выключается переключателем «Обложка трека в Discord» в настройках. Для уменьшения нужен Pillow (он в `requirements.txt`).

## Android

Мобильная версия называется **LAST FREQUENCY** и работает независимо от настольного плеера. Готовые APK лежат в `phone app/`: `Last-Frequency-arm64.apk` для большинства современных телефонов и `Last-Frequency-x86_64.apk` для Android Emulator. В мобильном приложении есть локальная библиотека, онлайн-поиск по YouTube Music, YouTube, SoundCloud, Deezer и Apple Music, воспроизведение превью и загрузка доступных треков в MP3.
