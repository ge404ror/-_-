# LAST FREQUENCY — Android

Нативное приложение-плеер для Android. Работает отдельно от Windows версии и не требует запущенного компьютера.

## Возможности

- Локальная музыкальная библиотека: импорт файлов и папок, поиск, сортировка, обложки и метаданные.
- Поиск по YouTube Music, YouTube, SoundCloud, Deezer и Apple Music; источники и тип результата (трек или плейлист) выбираются в меню поиска.
- Онлайн-треки можно добавить в плейлист без скачивания. При загрузке MP3 выбирается существующий плейлист или создаётся новый; папка загрузок задаётся в настройках. DRM-защищённый и платный контент не обходится, отдельные источники могут требовать авторизацию.
- Локальная библиотека распознаёт номер, исполнителя и название из имён вроде `41 - MARETU - 【初音ミク】 ニャン`; треки можно сортировать по номеру.
- Мини-плеер с перемоткой и громкостью. Нажатие на него открывает полноэкранный экран с обложкой и управлением; текст песни включается отдельной компактной кнопкой.
- Фон из обложки автоматически обновляется при смене трека и сохраняется между запусками приложения.
- Темы оформления, редактируемая тема и бас-буст с настройкой от 0 до 10×.
- Воспроизведение в фоне, системная медиасессия, уведомление и кнопки управления на экране блокировки.

## Установка

Скачай APK под устройство:

- `Last-Frequency-arm64.apk` — большинство современных Android телефонов.
- `Last-Frequency-x86_64.apk` — Android Emulator на ПК.

Минимальная версия — Android 7.0 (API 24). Разреши установку приложений из выбранного источника, открой APK и подтверди установку.

### Запуск на Android Emulator в Windows

Для проверки на ПК открой PowerShell в папке `phone app` и выполни:

```powershell
Set-Location 'E:\dowloads\саундларпище\Новая папка (6)\phone app'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_emulator.ps1
```

Скрипт выберет созданный виртуальный телефон, дождётся его полной загрузки, установит x86-64 APK и откроет LAST FREQUENCY. Для нескольких устройств он предложит выбрать одно. Если Android SDK лежит не в `E:\AndroidBuildTools\android-sdk`, укажи его путь:

```powershell
.\run_emulator.ps1 -SdkRoot 'ПУТЬ\К\Android\Sdk'
```

## Сборка

Нужны JDK 17 и Android SDK 35. На Windows:

```bat
gradlew.bat assembleDebug
```

Сборка создаёт отдельные APK под ARM64 и x86-64 в `app/build/outputs/apk/debug/`. Версия Android-модуля использует yt-dlp для Android и FFmpeg; сторонние уведомления и исходники перечислены в `THIRD_PARTY_NOTICES.md`.
