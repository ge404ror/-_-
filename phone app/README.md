# SoundLarp Phone

Мобильный клиент SoundLarp. Эту папку нужно развивать отдельно от Windows-приложения: Python backend, Windows tray и Tk mini-player на телефоне не запускаются.

## Функции мобильной версии

- Локальная библиотека и плейлисты с обложками.
- Поиск, сортировка, темы и управление воспроизведением.
- Фоновое аудио и системные controls на экране блокировки.
- Без плавающего мини-плеера.

## Статус

Исходники мобильного клиента и APK ещё не созданы. Для Android-разработки нужен Android Studio с Android SDK. Сборку и проверку IPA можно сделать только на Mac с Xcode.
